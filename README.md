# 🎭 TAKAR BUDAYA
**Tata Kalkulasi Partisipasi & Penonton Gelaran Acara Kebudayaan**  
*Berbasis Metodologi Herbert Jacobs, 1967 (P = A × D × T × C)*

---

## 🚀 Cara Menjalankan

### Cara 1: Menggunakan Docker
Pastikan Docker Desktop aktif, lalu jalankan di terminal folder ini:

```bash
docker compose up -d
```

Buka browser:
👉 **`http://localhost:8088`**

Untuk mematikan container:
```bash
docker compose down
```

---

### Cara 2: Tanpa Docker (Langsung Klik)
Karena aplikasi ini 100% *client-side* (HTML, CSS, dan JavaScript murni), Anda juga bisa langsung:
* Klik ganda (*double click*) file **`index.html`** untuk langsung membukanya di browser (Chrome, Edge, Safari, dll).
